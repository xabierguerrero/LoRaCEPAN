# Field measurements

## Default antenna

This measurements were made with the default antenna included with the Hellteck device. The measurements were taken with two devices, a sender and a receiver in a flat and open area. All the data is from the receiving device. However the first table has the data of both devices in receiver mode, even thou later on only one will work as a receiver and one as sender.

### Tests made with SF set to 8

> This first table has the data measured from a test done at 0m. The first entry is from the device that from now on will be the receiver and the second one from the from now on sender.
